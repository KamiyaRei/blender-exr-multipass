Manage render passes directly in the Compositor sidebar, with safer EXR output and the original large Create / Refresh buttons.

## Highlights
- Toggle current-layer Cycles/Eevee passes and synchronize EXR outputs immediately.
- Preserve manual processing links and frame positions on Refresh.
- Avoid AOV/beauty name collisions and give new setups distinct filenames.
- Fix disabled-pass removal in Blender 4.x.
- Collapse pass controls and output paths to keep the main panel compact.
- Stable package installation, reproducible ZIP and automated regression tests.

## Install
Download **EXR_Multipass_v1.7.1.zip** below, then use Preferences > Add-ons > Install from Disk. Do not install GitHub's Source code archive.

If you previously installed a single-file version, remove it and restart Blender before installing. Existing nodes are not deleted by uninstalling the add-on.

## Upgrade notes
- Recreate setups from 1.5.5 or earlier; there is no legacy-adoption command.
- Custom AOVs now use an `aov_` prefix; built-in Image still exports as `beauty`.
- Changes made in this panel synchronize automatically; changes made in Blender's own properties require Refresh.

Tested locally on Windows in Blender 4.5.11, 5.1.2 and 5.2.2. CI checks 4.5.11 and 5.2.2 on Linux. EXR tests validate output files and headers, not all downstream compositor workflows.

See CHANGELOG.md for the full update from 1.5.5. Intermediate 1.6.x and 1.7.0 builds were local previews.
